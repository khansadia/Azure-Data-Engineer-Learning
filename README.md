# Azure-Data-Engineer-Learning
# Azure Data Factory Learning Project

This repository contains my hands-on learning journey with
Azure Data Factory.

## Topics covered  
** Phase 1:**
   
    Azure Environment Setup: Step-by-step guide to creating a free Azure account and navigating the Azure Portal.
  Hierarchy and Organization: Explanation of Tenants, Subscriptions, and Resource Groups.
 Data Formats: Working with Structured (SQL), Semi-structured (JSON), and Unstructured (Media/Files) data.
   Azure SQL Database: Creating servers, databases, and managing firewall rules for connectivity.
**Phase 2:**
Data Ingestion & Orchestration (Azure Data Factory)
 * - Azure Data Factory (ADF) Full Course: Introduction to the backbone of Azure ETL/ELT processes.
 *  - Linked Services & Datasets: Mastering the fundamental connection logic between sources and destinations.
 *- Copy Activity: Learning to migrate data from web APIs, GitHub, and local file systems to the Data Lake.
 * Metadata & Control Flow: Using Get Metadata , For Each loops , and If Conditions to build dynamic, complex pipelines.
 *- Parameterized Pipelines: Building scalable solutions that handle multiple files dynamically using parameters.
    - Mapping Data Flows: Performing code-free data transformations using Spark-backed graphical interfaces.
 *  Automation & Triggers: Scheduling pipelines and setting up Storage Event Triggers  to automate ingestion when new files arrive

## Goal

Build an end-to-end Azure data pipeline and gradually
integrate Azure Data Factory with Azure Data Lake,
SQL and Power BI/Fabric.
